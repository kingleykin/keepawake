# Security policy

## Supported versions

Only the latest release of KeepAwake receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately instead:

1. Open the [Security tab](https://github.com/kingleykin/keepawake/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected version and operating system, and how to reproduce it.

You should get a first reply within 7 days. Once a fix is released, the report is published as a security advisory and you are credited unless you prefer otherwise.

## Scope

KeepAwake only asks the operating system to stop idle sleep. It does not run a network service, collect data, or need administrator rights. Reports about the installers, the update path, or the GitHub Actions release pipeline are also in scope.

---

## Chính sách bảo mật (Tiếng Việt)

Vui lòng **không** mở issue công khai cho lỗi bảo mật. Hãy vào [tab Security](https://github.com/kingleykin/keepawake/security), bấm **Report a vulnerability** và mô tả lỗi, phiên bản, hệ điều hành và cách tái hiện. Bạn sẽ nhận được phản hồi trong vòng 7 ngày.
